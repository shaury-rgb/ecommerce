# My Portfolio Projects

This repository contains data analytics and software engineering portfolio projects.

## Projects

### 1. [Mumbai Rental Market Analytics](./Mumbai_Rental_Analytics/)
A comprehensive data analytics project aimed at uncovering insights in the Mumbai real estate market. 

**Tech Stack:**
* Python (Pandas)
* PostgreSQL
* Power BI
* Matplotlib & Seaborn

**Key Features:**
* Custom realistic dataset generation and comprehensive data cleaning (imputation, standardization, outlier removal).
* Advanced SQL querying using CTEs, Window Functions, and Data Aggregation.
* Exploratory Data Analysis (EDA) uncovering correlations between property specifications and pricing.
* Interactive Power BI Dashboard design for high-level business insights.

To see the full details, code, and insights, navigate to the [Mumbai_Rental_Analytics](./Mumbai_Rental_Analytics/) directory.
